COMMON QUESTIONS

Engineered for security-conscious teams

How does it connect to AI tools without passwords?

add

Handoff Hub utilizes standard OAuth 2.0 PKCE and ephemeral scoped tokens. When connecting GitHub, Supabase, or Claude, authorization occurs on the provider's verified login page. Handoff Hub never intercepts or stores raw passwords or master credentials.

Does proprietary code get stored for model training?

add

Never. Handoff Hub acts purely as an encrypted transit mesh. Context shards and AST diffs are encrypted client-side with tenant-specific keys. Zero customer data is retained for training, and tokens are discarded as soon as handoffs conclude.

What happens when two assistants edit the same file?

add

The optimistic file-lock system alerts the second assistant that an active lock lease exists on the file (with remaining TTL). The incoming agent can either queue its patch or merge against the published AST brief once the first agent finishes.

Can I run Handoff Hub entirely on-premises?

add

Yes. Enterprise tiers include self-hosted docker configurations and Kubernetes Helm charts that connect directly to your own Redis / Postgres clusters with customer-managed AWS KMS keys.
